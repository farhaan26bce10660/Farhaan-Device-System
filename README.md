# Farhaan's Device System

A menu-driven Python application combining pattern printing and a calculator.

## Features
- Left, right and pyramid patterns
- Addition, subtraction, multiplication and division
- Mathematical operator precedence
- Division-by-zero protection
- Input validation and calculator restart

## Run
`python main.py` (or `py main.py` on Windows)

## Tests
`python -m unittest discover -s tests`

## Technologies
Python 3, VS Code, Git/GitHub, standard library only.
