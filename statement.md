# Project Statement

## Problem Statement
Basic Python applications often require separate programs for different utilities. This project combines a pattern printing game and calculator in one menu-driven console system.

## Scope
A beginner-friendly console application demonstrating loops, conditions, variables, functions, modules, validation and arithmetic operations.

## Target Users
Students and beginners learning Python programming.

## High-Level Features
1. Menu-driven interface
2. Pattern printing
3. Calculator
4. Input validation
5. Division-by-zero protection
6. Restart and exit controls
